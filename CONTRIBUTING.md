# Como colaborar

Este repositório está na etapa de planejamento. Antes de iniciar a implementação, a equipe deve validar a proposta, definir integrantes e responsáveis, escolher o quadro de tarefas e confirmar as tecnologias.

## Fluxo sugerido

1. Registre cada atividade no quadro escolhido e indique responsável e critério de conclusão.
2. Crie uma branch curta a partir de `main` para cada atividade; use nomes como `docs/requisitos` ou `feat/agenda-diaria`.
3. Faça commits pequenos, com mensagens claras e relacionadas à atividade.
4. Revise as alterações e integre-as à `main` por pull request quando a equipe estiver usando esse fluxo.
5. Mantenha o README, o backlog e as limitações conhecidos atualizados.

## Cuidados

- Não publique credenciais, dados pessoais reais ou informações de clientes.
- Use dados fictícios no desenvolvimento e nas demonstrações.
- Não marque uma funcionalidade como concluída antes de verificar os critérios de aceitação definidos pela equipe.
- Registre mudanças de escopo e decisões que afetem a equipe.
